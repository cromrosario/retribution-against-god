# TEST_ui2 — HP/MPを一番下へ・選択肢を小さく・挿絵をさらに大きく

対象: `tools/apply_ui2.py`(`UI2-CSS` ブロック)。テストは Git 側で行う。

## 静的チェック
1. `UI2-CSS:BEGIN/END` が各1件で、`BGFIX-CSS:END` の後ろにある。
2. `body:not(.fighting) .me { order: 99; }` がある。
3. `min-height: 28px` の選択肢規則と、`aspect-ratio: 4 / 3` の挿絵規則がある。

## 画面チェック(Playwright、393×852)
1. 戦闘外(部屋選択・イベント): `#hud` の下端が、`.app` の下端(安全領域の余白を除く)に近い。`#hud` の位置が `#choices` より下。
2. 戦闘中: `#hud` が `#choices` より上(従来どおり)。
3. イベントの選択肢ボタンの高さが 32px 以下(1行の場合)。
4. 挿絵のあるイベントで、`.ev-art` の幅が `window.innerWidth` に近い(±4px)。高さが `innerHeight` の 42% 以下。
5. JS エラーが出ない。

## 実機確認
- HP/MP が一番下に出ているか(ホームバーに被らないか)。
- 選択肢が小さすぎて押しにくくないか(目安: 28px。押しにくければ UI2-CSS の `min-height` を 32px に)。
- 挿絵の左右が切れすぎていないか(4:3 に縦長化したぶん、左右が少し切れる)。切れすぎなら比率を 378 / 250 に戻す。
